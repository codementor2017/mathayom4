Algorithm Design for Complete Systems

Why This Matters

Think of a path through the forest. Each stone leads to the next, and if you follow them in order, you reach your destination. That is exactly what an algorithm is: a clear sequence of steps that solves a problem.

But a project is more than one algorithm. It is many algorithms working together. In this lesson, you will learn how to write algorithms for each sub-system and then connect them into one complete system.

What You Will Learn

  • Write algorithms for each sub-system.
  • Connect sub-system algorithms into one complete system.
  • Use pseudocode to describe the full system.

Words to Know

algorithm pseudocode sub-system logic sequence condition loop integration

Lesson Journey (100 minutes)

Part 1 — From Sub-System to System 0–10 min

Ask yourself: If you have algorithms for each sub-system, how do they work together?

They need to exchange data and trigger each other. That is what we call system-level algorithm design.

Part 2 — Writing System Algorithms 10–30 min

Follow this process:

  1. Write pseudocode for each sub-system.
  2. Identify inputs and outputs of each sub-system.
  3. Connect them: output of one = input of another.
  4. Write a main algorithm that calls each sub-system.

Example — Automatic plant control system:

MAIN:
  LOOP forever:
    moisture = read_soil_sensor()
    IF moisture < threshold:
      turn_pump_on()
    ELSE:
      turn_pump_off()
    log_data(moisture)
    display_status()

The main algorithm orchestrates the sub-systems.

Part 3 — Practise Together: Library System 30–55 min

Let's write the system algorithm for the library system together:

  • Sub-system algorithms: search, recommend, display, borrow.
  • Main algorithm: user logs in → search → recommend → borrow → log.

Write on the board together.

Part 4 — Your Turn: Design Your System Algorithm 55–85 min

Write pseudocode for:

  • Each sub-system (at least 5).
  • The main algorithm that connects them.

Test your logic by walking through a sample scenario with your group.

Part 5 — Share and Discuss 85–95 min

Present your system algorithm.

Discuss: What was the hardest part of connecting the sub-systems?

Part 6 — Exit Ticket 95–100 min

Write the main algorithm for your project in 5 steps.

Check Your Understanding

You are ready to move on when you can write pseudocode for the full system.

Support: Use a pseudocode template with sub-system placeholders.

Challenge: Can you add error handling to the main algorithm?
