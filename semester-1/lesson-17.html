Building the First Prototype

Previous Course Home Next Lesson
100 minutes Phase 5 · Initial Prototype Building Prototype Development

Why This Matters

A prototype is a simple version of your project that shows the main idea. Instead of building everything at once, you build the smallest working version first — called the MVP (Minimum Viable Product). This is how real software teams work.

What You Will Learn

  • Build a basic prototype of your project.
  • Focus on core functionality first.
  • Document your progress.

Words to Know

prototype minimum viable product (MVP) core feature iteration build test

Lesson Journey (100 minutes)

Part 1 — What is a Prototype? 0–10 min

Ask yourself: What is a prototype?

A simple version that shows the main idea. Build the simplest version that works first.

Part 2 — MVP Approach 10–30 min

Follow the MVP approach:

  1. Identify the core feature.
  2. Build only that feature.
  3. Test it.
  4. Add more features later.

Example for the library system:

  • MVP: search by title only.
  • Next: search by author.
  • Next: recommendations.
  • Next: borrowing history.

Part 3 — Plan Your MVP Together 30–55 min

Identify the MVP for the library system.

Write the plan on the board.

Part 4 — Your Turn: Build Your Prototype 55–85 min

Build your MVP in Python:

  • Focus on the core feature.
  • Document progress in the prototype log.
  • Test as you build.

Example Python starter:

books = ["Harry Potter", "The Hobbit", "Dune"]

def search(title):
    results = [b for b in books if title.lower() in b.lower()]
    return results

print(search("harry"))

Part 5 — Share and Discuss 85–95 min

Share your progress.

Discuss: What was the hardest part of building?

Part 6 — Exit Ticket 95–100 min

What is your MVP, and what does it do?
