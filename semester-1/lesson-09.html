Project Lifecycle and Development Phases

Previous Course Home Next Lesson
100 minutes Phase 3 · Project Planning & Management Phases of a Project

Why This Matters

Every project follows a lifecycle — just like a plant grows from seed to fruit. Understanding the phases helps you plan your work, know what comes next, and avoid getting lost.

What You Will Learn

  • Describe the phases of a project lifecycle.
  • Identify what happens in each phase.
  • Map your project to the lifecycle.

Words to Know

lifecycle initiation planning execution monitoring closure deliverable milestone

Lesson Journey (100 minutes)

Part 1 — How Does a Project Start and End? 0–10 min

Ask yourself: How does a project begin? How does it end?

Idea → plan → build → test → present → reflect.

Every project follows a lifecycle.

Part 2 — The Five Phases 10–30 min

Learn the phases:

  • Initiation: define the problem, goals, and scope.
  • Planning: timeline, roles, resources, risks.
  • Execution: build the system, write code, create content.
  • Monitoring: test, get feedback, fix issues.
  • Closure: present, document, reflect.

Each phase produces deliverables.

Part 3 — Map a Sample Project 30–55 min

Map the automatic plant control project:

  • Initiation: problem statement, user needs.
  • Planning: timeline, sensor list, roles.
  • Execution: build sensor module, logic, pump, UI.
  • Monitoring: test with real plants, fix bugs.
  • Closure: present, document, reflect.

Part 4 — Your Turn: Map Your Project 55–85 min

Create a lifecycle diagram for your project:

  • What happens in each phase?
  • What are the deliverables?
  • Who is responsible?

Part 5 — Share and Discuss 85–95 min

Present your lifecycle diagram.

Discuss: Which phase will be the most challenging? Why?

Part 6 — Exit Ticket 95–100 min

Name the five phases of a project lifecycle.

Check Your Understanding
