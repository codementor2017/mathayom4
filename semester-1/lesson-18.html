Basic User Interface Design

Previous Course Home Next Lesson
100 minutes Phase 5 · Initial Prototype Building UI Design

Why This Matters

Your system might work perfectly, but if the user cannot understand it, it has failed. A good user interface (UI) makes your project easy and pleasant to use. In this lesson, you will design UI mockups for your project.

What You Will Learn

  • Apply UI design principles.
  • Create a UI mockup for your project.
  • Test the UI with a user.

Words to Know

user interface mockup wireframe layout color typography accessibility

Lesson Journey (100 minutes)

Part 1 — Good vs Bad UI 0–10 min

Look at two app screens: one clear, one cluttered.

Which is easier to use? Why?

Good UI makes your project usable.

Part 2 — UI Design Principles 10–30 min

The 5 principles:

  • Simplicity: one screen, one purpose.
  • Consistency: same colours, fonts, buttons.
  • Feedback: show what happened.
  • Accessibility: large text, clear contrast.
  • Hierarchy: most important first.

Part 3 — Create a UI Mockup Together 30–55 min

Design for the library system:

  • Search screen.
  • Results screen.
  • Book details screen.

Draw on the board or in Figma.

Part 4 — Your Turn: Design Your UI 55–85 min

Create UI mockups for your project:

  • At least 3 screens.
  • Label all elements.
  • Show user flow between screens.

Test with a classmate.

Part 5 — Share and Discuss 85–95 min

Present your UI.

Discuss: What did your test user say about your UI?

Part 6 — Exit Ticket 95–100 min

List 3 UI principles you applied.

Check Your Understanding

You are ready to move on when you can design and test a UI.

Support: Use a UI template.

Challenge: Create a responsive design.
