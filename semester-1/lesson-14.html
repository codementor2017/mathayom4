System Architecture and Component Design

Previous Course Home Next Lesson
100 minutes Phase 4 · System Design & Requirements Architecture Diagram

Why This Matters

Architecture is the blueprint of your system. It shows how the parts connect, like the layers of a tree trunk or the frame of a bridge. In this lesson, you will design the three layers of your system: presentation, logic, and data.

What You Will Learn

  • Design a system architecture.
  • Identify components and their connections.
  • Draw an architecture diagram.

Words to Know

architecture component module interface connection layer client-server

Lesson Journey (100 minutes)

Part 1 — How Do Parts Connect? 0–10 min

Ask yourself: How do the parts of your system connect?

  • User interface connects to logic.
  • Logic connects to database.

Architecture shows how components connect.

Part 2 — Architecture Design 10–30 min

Learn the three layers:

  • Presentation layer: what the user sees (UI).
  • Logic layer: what the system does (processing, decisions).
  • Data layer: where data is stored (database, files).

Connections:

  • User → UI → Logic → Data → Logic → UI → User.

Example for the library system:

  • Presentation: search page, results page, book details.
  • Logic: search engine, recommendation engine, borrow logic.
  • Data: book database, user database, borrowing history.

Part 3 — Draw the Architecture Together 30–55 min

Draw the architecture for the library system.

Label each component and connection.

Part 4 — Your Turn: Design Your Architecture 55–85 min

Draw your architecture:

  • Components.
  • Layers.
  • Connections.
  • Data flow direction.

Part 5 — Share and Discuss 85–95 min

Present your architecture.

Discuss: Which component is most critical?

Part 6 — Exit Ticket 95–100 min

Draw and label the three layers of your system.

Check Your Understanding

You are ready to move on when you can design a system architecture.

Support: Use an architecture template with labeled layers.

Challenge: Add external services (APIs, cloud).
