Semester 1 · Lesson 16

Choosing Tools and Technologies

Previous Course Home Next Lesson
100 minutes Phase 4 · System Design & Requirements Tool Selection

Why This Matters

Choosing the right tool saves time and effort. In this lesson, you will compare tools and create a technology plan for your project. Your main tool will be Python, supported by a database and optional hardware.

What You Will Learn

  • Identify tools and technologies for your project.
  • Compare options based on requirements.
  • Create a technology plan.

Words to Know

tool technology framework platform library database sensor API

Lesson Journey (100 minutes)

Part 1 — What Tools Do You Need? 0–10 min

Ask yourself: What tools will you need to build your project?

  • Programming language
  • Database
  • Sensors
  • Framework
  • Hosting

Choosing the right tools saves time and effort.

Part 2 — Tool Options 10–30 min

Compare the options:

  • Programming: Python, JavaScript, Java, AppInventor.
  • Database: SQLite, MySQL, Google Sheets, Firebase.
  • Web: Flask, Django, React.
  • IoT: Arduino, Raspberry Pi, ESP32.
  • Sensors: temperature, humidity, motion, soil moisture.
  • APIs: weather, maps, translation.

Compare using these criteria:

  • Cost.
  • Ease of use.
  • Features.
  • Community support.
  • Compatibility.

Part 3 — Compare Tools Together 30–55 min

Use the library system as an example:

  • Python vs JavaScript for the backend.
  • SQLite vs Google Sheets for the database.
  • Flask vs Django for the web framework.

Choose the best combination.

Part 4 — Your Turn: Create Your Technology Plan 55–85 min

Create a technology plan:

  • Tool for each component.
  • Why chosen.
  • Alternatives considered.
  • Cost and availability.

Part 5 — Share and Discuss 85–95 min

Present your technology plan.

Discuss: What tool are you most excited to use?

Part 6 — Exit Ticket 95–100 min

List 3 tools you will use and why.

Check Your Understanding

You are ready to move on when you can choose appropriate tools for your project.

Challenge: Prototype with two different tools.
