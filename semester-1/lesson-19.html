Semester 1 · Lesson 19

Connecting Components

Previous Course Home Next Lesson
100 minutes Phase 5 · Initial Prototype Building Integration

Why This Matters

A system only works when its parts work together. In this lesson, you will connect your UI, your logic, and your data into one integrated prototype. This is called integration, and it is the moment your project comes alive.

What You Will Learn

  • Connect your UI to your logic.
  • Connect your logic to your data.
  • Test the integrated prototype.

Words to Know

integration connection API data binding event trigger response

Lesson Journey (100 minutes)

Part 1 — Why Integrate? 0–10 min

Ask yourself: Why do we need to connect components?

  • So the user can see results.
  • So data can be saved.
  • So recommendations can be shown.

Integration makes the system work as a whole.

Part 2 — Integration Methods 10–30 min

Learn the methods:

  • UI to logic: event triggers function (button click → search).
  • Logic to data: function queries database (search → SELECT).
  • Data to UI: results displayed (query results → list).

Example flow:

  • User types "Harry Potter" → search() → database query → results → display.

Part 3 — Connect Components Together 30–55 min

Connect:

  • Search UI to search function.
  • Search function to database.
  • Database results to results UI.

Test together.

Part 4 — Your Turn: Integrate Your Prototype 55–85 min

Connect your components in Python:

  • UI to logic.
  • Logic to data.
  • Data back to UI.

Test the integrated prototype.

Part 5 — Share and Discuss 85–95 min

Share your integrated prototype.

Discuss: What was the hardest part of integration?

Part 6 — Exit Ticket 95–100 min

Describe the flow of data in your integrated prototype.

Check Your Understanding

You are ready to move on when you can connect UI, logic, and data.

Support: Use integration templates or starter code.

Challenge: Add error handling.

Before Next Lesson

Complete your integrated prototype and log any bugs.
