Writing Basic Queries

Previous Course Home Next Lesson
100 minutes Phase 6 · Data Modeling & Database Design SELECT, INSERT, UPDATE

Why This Matters

A database is useless if you cannot ask it questions. SQL is the language for talking to databases. In this lesson, you will learn to write queries that find, add, and update data — the same queries real apps use every day.

What You Will Learn

  • Write SELECT queries.
  • Write INSERT and UPDATE queries.
  • Use WHERE clauses to filter data.

Words to Know

query SELECT INSERT UPDATE DELETE WHERE FROM ORDER BY

Lesson Journey (100 minutes)

Part 1 — How Do You Get Data? 0–10 min

Ask yourself: How do you get data from a database?

You ask questions using queries.

SQL is the language for talking to databases.

Part 2 — Basic SQL 10–30 min

Learn these queries:

SELECT * FROM Books;
SELECT Title, Author FROM Books;
SELECT * FROM Books WHERE Genre = 'Fantasy';
INSERT INTO Books (Title, Author) VALUES ('New Book', 'Author');
UPDATE Books SET Available = 'No' WHERE BookID = 1;
DELETE FROM Books WHERE BookID = 2;

See each query with its results.

Part 3 — Write Queries Together 30–55 min

Write 8 queries for the library system.

Test each query in SQLite.

Part 4 — Your Turn: Write Your Queries 55–85 min

Write queries for your project:

  • At least 3 SELECT queries.
  • 1 INSERT.
  • 1 UPDATE.
  • 1 DELETE.
  • 2 queries with WHERE.

Test in SQLite or Google Sheets.

Part 5 — Share and Discuss 85–95 min

Present your queries.

Discuss: Which query is most important for your project?

Part 6 — Exit Ticket 95–100 min

Write a SELECT query that finds all records where the genre is 'Science'.

Check Your Understanding

You are ready to move on when you can write basic SQL queries.

Support: Use a SQL cheat sheet.

Challenge: Use JOIN and GROUP BY.
