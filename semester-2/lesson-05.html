Semester 2 · Lesson 5

Designing Interactive User Interfaces

Previous Course Home Next Lesson
100 minutes Phase 7 · User Interaction & Interface Interactive UI

Why This Matters

A static screen is boring. An interactive UI responds to what the user does — clicking, typing, selecting. In this lesson, you will design interactions that make your project feel alive.

What You Will Learn

  • Design interactive UI features.
  • Plan user interactions.
  • Create an interactive mockup.

Words to Know

interactive user interface event response feedback flow prototype

Lesson Journey (100 minutes)

Part 1 — What Makes UI Interactive? 0–10 min

Ask yourself: What makes an app interactive?

  • Buttons
  • Forms
  • Search
  • Feedback
  • Navigation

Interactive UI responds to the user.

Part 2 — Interaction Design 10–30 min

Learn the interaction types:

  • Input: text, selection, upload.
  • Action: button click, swipe, submit.
  • Response: display, alert, redirect, update.
  • Feedback: success, error, loading.

Examples:

  • Search box → search results.
  • Like button → heart fills.
  • Submit form → confirmation message.

Part 3 — Design Interactions Together 30–55 min

Design interactions for the library system:

  • Search input.
  • Filter buttons.
  • Result cards.
  • Borrow button.
  • Confirmation message.

Part 4 — Your Turn: Design Your Interactions 55–85 min

Design your interactions:

  • At least 5 interactive features.
  • User flow.
  • Feedback for each action.

Part 5 — Share and Discuss 85–95 min

Present your interactive mockup.

Discuss: Which interaction is most important for your user?

Part 6 — Exit Ticket 95–100 min

Describe one interaction and its feedback.

Check Your Understanding

You are ready to move on when you can design interactive features with feedback.

Support: Use an interaction template.

Challenge: Add animations.
