Automation Logic: Sensors to Actions

Previous Course Home Next Lesson
100 minutes Phase 8 · Automation & Integration Sensors, Decisions, Actions

Why This Matters

Automation is what makes a system smart. Instead of a human checking the soil every hour, a sensor reads the moisture, the system decides if water is needed, and an action happens automatically. This is the heart of smart systems.

What You Will Learn

  • Explain the sensor → decision → action cycle.
  • Build a simple automation module.
  • Test the module with simulated data.

Words to Know

automation sensor decision action threshold trigger actuator

Part 2 — Sensor → Decision → Action 10–30 min

The cycle:

  • Sensor: reads data (soil moisture = 20%).
  • Decision: compares to threshold (20% < 30%? Yes).
  • Action: turns on pump.

Python simulation:

def read_sensor():
    return 20  # simulate

def control_pump(state):
    print("Pump:", state)

threshold = 30
moisture = read_sensor()

if moisture < threshold:
    control_pump("ON")
else:
    control_pump("OFF")
