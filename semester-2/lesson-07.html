Recommendation and Feedback Systems

100 minutes Phase 7 · User Interaction & Interface Recommendations, Feedback

Why This Matters

Apps like Netflix and YouTube use recommendations to keep you interested. In the same way, your project can use data to suggest things users might like, and collect feedback to improve over time.

What You Will Learn

  • Build a recommendation feature.
  • Build a feedback feature.
  • Use user data to improve recommendations.

Words to Know

recommendation feedback personalization rating filter algorithm

Lesson Journey (100 minutes)

Part 1 — How Do Apps Recommend? 0–10 min

Ask yourself: How does Netflix or YouTube recommend videos?

  • Based on what you watched.
  • Based on what you liked.
  • Based on what you searched.

Recommendations use user data.

Part 2 — Recommendation Logic 10–30 min

Learn the types:

  • Content-based: recommend similar items.
  • Collaborative: recommend what similar users liked.
  • Popularity-based: recommend popular items.

Feedback types:

  • Ratings (1–5 stars).
  • Likes/dislikes.
  • Comments.

Example recommendation algorithm in Python:

def recommend(user_history, all_books):
    genres = [book.genre for book in user_history]
    return [b for b in all_books if b.genre in genres and b not in user_history]

Part 3 — Build a Recommendation Together 30–55 min

Build a simple recommendation for the library system.

Part 4 — Your Turn: Build Recommendation and Feedback 55–85 min

Build:

  • A recommendation feature.
  • A feedback feature (rating or like).

Use feedback to improve recommendations.

Part 5 — Share and Discuss 85–95 min

Share your recommendation feature.

Discuss: How does your recommendation improve over time?

Part 6 — Exit Ticket 95–100 min

Explain the logic of your recommendation feature.
