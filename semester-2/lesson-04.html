Why This Matters

Now that you can write queries, you need to connect them to your Python program. This is where your project becomes alive — the code can read data, display it, and save new data back. You will use Python + SQLite, the easiest combination for beginners.

What You Will Learn

  • Connect a Python program to a database.
  • Read data from the database.
  • Write data to the database.

Words to Know

connection cursor fetch commit SQLite Python database driver

Lesson Journey (100 minutes)

Part 1 — How Does Code Talk to Data? 0–10 min

Ask yourself: How does your code get data from the database?

Through a connection and queries.

Programs connect to databases using a driver.

Part 2 — Python + SQLite 10–30 min

Here is the basic code:

import sqlite3

conn = sqlite3.connect('library.db')
cursor = conn.cursor()

cursor.execute("SELECT * FROM Books WHERE Genre = ?", ("Fantasy",))
results = cursor.fetchall()

for row in results:
    print(row)

conn.close()

What each part does:

  • connect() opens the database.
  • cursor() creates a cursor.
  • execute() runs a query.
  • fetchall() gets all results.
  • close() closes the connection.
