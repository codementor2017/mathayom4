Semester 1 — Foundation, Planning, Design & Prototype

Build the foundation: from computational thinking to your first working prototype.

Phase 1 · Computational Thinking Foundations

Lessons 1–4

The 4 pillars at project scale: decomposition, pattern recognition, abstraction, and algorithm design.

  • Lesson 1 · Introduction to Computational Thinking
  • Lesson 2 · Decomposition in Real-World Projects
  • Lesson 3 · Pattern Recognition and Abstraction
  • Lesson 4 · Algorithm Design for Complete Systems

Phase 2 · Problem Identification & Scoping

Lessons 5–8

Observe real problems, distinguish symptoms from root causes, and conduct user needs assessments.

  • Lesson 5 · Observing and Identifying Real Problems
  • Lesson 6 · Conducting User Needs Assessment
  • Lesson 7 · Writing Problem Statements and Goals
  • Lesson 8 · Exploring Domains

Phase 3 · Project Planning & Management

Lessons 9–12

Project lifecycle, timelines, team roles, and risk assessment with documentation.

  • Lesson 9 · Project Lifecycle and Development Phases
  • Lesson 10 · Timeline, Milestones, and Task Breakdown
  • Lesson 11 · Roles, Responsibilities, and Teamwork
  • Lesson 12 · Risk Assessment and Documentation

Phase 4 · System Design & Requirements

Lessons 13–16

Functional & non-functional requirements, system architecture, DFDs, and tool selection.

  • Lesson 13 · Functional and Non-Functional Requirements
  • Lesson 14 · System Architecture and Component Design
  • Lesson 15 · Data Flow Diagrams and Process Modeling
  • Lesson 16 · Choosing Tools and Technologies

Phase 5 · Initial Prototype Building

Lessons 17–20

Build your first prototype using the MVP approach, design a basic UI, and connect components.

  • Lesson 17 · Building the First Prototype
  • Lesson 18 · Basic User Interface Design
  • Lesson 19 · Connecting Components
  • Lesson 20 · Semester 1 Review and Milestone
Semester 1 Output: A working prototype with core functionality, a complete project plan, system design documents, and a milestone presentation.

Semester 2 — Database, Interaction, Automation, Testing & Presentation

Make your project real: add data, interactivity, automation, testing, and present your final project.

Phase 6 · Data Modeling & Database Design

Lessons 1–4

Design data models, create ER diagrams, write SQL queries, and connect programs to databases.

  • Lesson 1 · Introduction to Data Modeling
  • Lesson 2 · Database Tables and Relationships
  • Lesson 3 · Writing Basic Queries
  • Lesson 4 · Connecting Programs to Databases

Phase 7 · User Interaction & Interface

Lessons 5–8

Design interactive UIs, build forms and search features, and add recommendation & feedback systems.

  • Lesson 5 · Designing Interactive User Interfaces
  • Lesson 6 · Building Input Forms and Search Features
  • Lesson 7 · Recommendation and Feedback Systems
  • Lesson 8 · Accessibility and Error Handling

Phase 8 · Automation & Integration

Lessons 9–12

Automation logic, IoT integration, real-time data collection, and domain-specific automation.

  • Lesson 9 · Automation Logic: Sensors to Actions
  • Lesson 10 · IoT Integration for Real-World Projects
  • Lesson 11 · Real-Time Data Collection and Response
  • Lesson 12 · Energy and Agriculture Automation

Phase 9 · Testing & Iteration

Lessons 13–16

Create test plans, conduct usability testing with real users, analyze feedback, and iterate.

  • Lesson 13 · Creating a Test Plan
  • Lesson 14 · Usability Testing with Real Users
  • Lesson 15 · Collecting and Analyzing User Feedback
  • Lesson 16 · Iterating and Improving the Project

Phase 10 · Ethics, Impact & Presentation

Lessons 17–20

Assess social & environmental impact, apply privacy principles, and prepare your final portfolio.

  • Lesson 17 · Social and Environmental Impact
  • Lesson 18 · Data Privacy and Responsible Innovation
  • Lesson 19 · Preparing the Project Portfolio
  • Lesson 20 · Final Project Presentation and Reflection
Semester 2 Output: A complete project with a working database, interactive UI, automation features, testing documentation, impact assessment, privacy plan, portfolio, and final presentation.

How You Will Be Assessed

  • Problem statement — clear, specific, measurable
  • User needs — 5+ users assessed, 2+ personas
  • Computational thinking — all 4 pillars applied deeply
  • Subject integration — deep, creative integration
  • Project planning — full lifecycle with timeline, roles, risks
  • System design — complete architecture + DFD + ER
  • Database — working database with 3+ tables
  • User interaction — interactive UI with feedback
  • Automation — working automation with sensors
  • Testing — full test plan + usability testing
  • Iteration — 2+ documented iterations
  • Impact assessment — detailed social + environmental
  • Privacy — full privacy plan
  • Portfolio — complete with all sections
  • Presentation — clear, confident, engaging
  • Reflection — insightful and detailed

Tools You Will Use

  • Programming: Python, JavaScript, AppInventor
  • Web Frameworks: Flask, Django, React
  • Databases: SQLite, MySQL, Google Sheets, Firebase
  • IoT & Hardware: Arduino, Raspberry Pi, ESP32, sensors
  • Design: Figma, Canva
  • Project Management: Google Sheets (Gantt charts)

Course Expectations

One project, all year
Teamwork in groups of 3–4
Real-world connection
Subject integration
Database required
User interaction required
Testing with real users
Impact assessment required
Portfolio required
End-of-year showcase
